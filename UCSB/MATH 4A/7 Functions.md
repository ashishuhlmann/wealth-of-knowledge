A **function** is a rule that maps the inputs from a **domain** to *exactly one* output in the **codomain**.
- Two elements can get mapped to the same output, but one element cannot get mapped to two distinct outputs.
$$f:D\rightarrow C$$
$$f:\mathbb{R}\rightarrow\mathbb{R}$$
- **preimage** $x\rightarrow$ **image** $f(x)$

A **linear transformation** is a function that takes in a vector and gives out another vector.

Let $T$ be a linear transformation by:
$$
T:\mathbb{R}^{n}\rightarrow\mathbb{R}^{m}
$$
If $\vec{x}\in\mathbb{R}^{n}$ then $T(\vec{x})$ is called the **image** of $\vec{x}$ under $T$.
The **image** of $T$ denoted by $\text{im}(T)$ is the set of all $T(\vec{x})|\vec{x}\in\mathbb{R}^{n}$ (range).

A **one to one function** or **injective function** is a function where distinct elements in the domain get mapped to distinct elements inthe codomain.

An **onto** or **subjective** function is a function where every element in the codomain has a preimage.

A **bijective** function is both onto and one to one.
